# Shoe-dryer
功能
实时采集：温湿度、空气质量、柜门状态
设备控制：烤灯、风扇、消毒 / 夜间灯
安全保护：柜门开启时禁止加热、消毒设备运行
小程序远程监控、手动控制、状态实时同步
硬件
主控：STM32F103（裸机开发）
传感器：DHT11、空气质量传感器、霍尔门磁
执行器：烤灯、风扇、LED / 消毒灯
通信：ESP8266 WiFi 模块
软件
单片机：裸机轮询 + 定时器、UART 串口通信、AT 指令连 WiFi
小程序：WXML 布局、WXSS 样式、JS 逻辑、WebSocket 实时通信
通信方式：WebSocket 双向长连接，数据主动上传、指令实时下发
核心技术
STM32F103 裸机开发
ESP8266 WiFi 联网
WebSocket 实时通信
小程序数据绑定与事件控制
安全联锁与状态保护逻辑# Shoe-dryer
